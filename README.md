# Guía para la Identificación del Phishing

Este repositorio forma parte de la **tesina para la obtención del grado de Ingeniera en Computación**, desarrollada en la **Universidad Nacional Autónoma de México (UNAM)**.

Contiene una **guía para la identificación del phishing** y **material gráfico (infografías)** elaborados como apoyo educativo para la concientización y comprensión de este tipo de ataque de ingeniería social.


El enfoque del material es **educativo y preventivo**, orientado a fortalecer la capacidad de los usuarios para identificar intentos de phishing.

---

## 📂 Contenido del repositorio

- 📄 **Guía para la identificación del phishing**  
  Documento que aborda el concepto de phishing, sus principales características, tipos comunes, y señales de alerta para su identificación.

- 🖼️ **Infografías educativas**  
  Material visual complementario diseñado para resumir los conceptos presentados en la guía y facilitar su lectura.

- 📝 **Nota**
  Tanto la guía como las infografías cuentan con una codificación de colores para facilitar la identificación de las acciones clave para reconocer el phishing en los ejemplos.

---

## 🎯 Objetivo

El objetivo principal de este repositorio es:
- Contribuir a la **concientización en ciberseguridad** en este caso orientado al phishing.
- Proporcionar recursos educativos para la **identificación del phishing**.
- Servir como material de apoyo en **contextos académicos y formativos**.
